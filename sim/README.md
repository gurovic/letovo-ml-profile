# sim/ — Симуляция студента и оценщик программы

Подпроект для вероятностной оценки качества программы профиля «Машинное обучение» (8 класс).

## Идея

Симулируем N студентов, каждый из которых проходит 68 пар программы.
Модель памяти (spacing effect) отслеживает, в каком состоянии находится каждая тема к концу года.
Затем «экзаменатор» сопоставляет итоговые состояния с портретом выпускника (Foundation §3)
и выдаёт системные рекомендации по программе.

## Установка

Зависимости: только стандартная библиотека Python 3.9+ и `PyYAML`.

```powershell
pip install pyyaml
```

## Быстрый старт

```powershell
# из корня репозитория
python sim/run.py --students 100 --seed 42
```

Сохранить отчёт:

```powershell
python sim/run.py --students 100 --seed 42 --out sim/results/latest.md
```

Один студент с подробным логом:

```powershell
python sim/run.py --students 1 --verbose --seed 7
```

## Архитектура

```
modules/08_*/lessons/*
    ↓ parse_curriculum.py
[(pair_id, module, [concept_tags]), ...]
    ↓ student.py × N
[SimResult, ...]          ← вероятностная модель памяти (Beta capacity)
    ↓ examiner.py × N
[ExamReport, ...]         ← балл по 5 компетенциям Foundation §3
    ↓ evaluator.py
AggregateReport           ← pass rates, weak topics, рекомендации
```

## Модель памяти

Каждая тема проходит через состояния:

| Состояние | Условие |
|---|---|
| `unseen` | Тема не встречалась |
| `met` | 1-я встреча, p=0.9 |
| `practiced` | 2-я встреча в окне ≤8 пар, p=0.75 |
| `mastered` | 3-я встреча в окне ≤12 пар, p=0.85 |
| `forgotten` | Превышено окно повторения |

`student_capacity ~ Beta(8, 2)` — масштабирует все вероятности переходов.
Среднее capacity ≈ 0.8; слабый студент — ниже, сильный — выше.

## Компетенции (Foundation §3)

| Ключ | Описание |
|---|---|
| C1_programming | Программирует как инженер |
| C2_data | Работает с данными |
| C3_ml | Применяет ML |
| C4_math | Мыслит математически |
| C5_artifacts | Создаёт артефакты |

Маппинг тем → компетенции: `sim/competency_map.yaml`.

## Интерпретация отчёта

| graduate_profile_rate | Вывод |
|---|---|
| ≥ 80% | Программа хорошо формирует выпускника |
| 65–80% | Приемлемо, есть точки роста |
| < 65% | Требует усиления повторения ключевых тем |

Weak topics — темы, встречающиеся редко или с большим разрывом между встречами.
После правки материалов уроков — перезапустить `run.py` и сравнить отчёты.

## Файлы

| Файл | Назначение |
|---|---|
| `parse_curriculum.py` | Парсер `LESSON.md` + `lesson/homework/solutions.ipynb` → список пар с concept-тегами |
| `student.py` | Вероятностная модель памяти студента |
| `examiner.py` | Оценка SimResult по 5 компетенциям |
| `evaluator.py` | Агрегация N прогонов → AggregateReport |
| `run.py` | CLI точка входа |
| `competency_map.yaml` | Маппинг тег тема → компетенция + веса |
| `results/` | Сохранённые отчёты (в .gitignore) |

## Ограничения

- Модель не учитывает домашние задания и артефакты как отдельные встречи с темой.
- Теги тем извлекаются эвристически из текстов урока и ноутбуков — при неточном парсинге скорректировать правила в `parse_curriculum.py`.
- Маппинг в `competency_map.yaml` — подстрочный (substring match), не NLP. Уточнить веса при расхождении с экспертной оценкой.
- `results/` исключён из git (см. `.gitignore`).
