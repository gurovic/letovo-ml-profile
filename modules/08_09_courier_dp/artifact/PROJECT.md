# Артефакт модуля: DP-набор для службы «Мгновение»

**Тип:** заполненный `homework.ipynb` + короткая инженерная нота  
**Срок:** пара КТП **63**  
**Файл сдачи:** `lessons/05_games_when_dp/homework.ipynb`

---

## Задача

1. Реализовать минимум 2 решения DP 1D (размен и линейный максимум/план).
2. Реализовать минимум 2 решения DP 2D (маршрут и табличный шаблон).
3. Реализовать win/lose игру с заданным набором ходов.
4. Сдать ноту «когда DP уместен в инженерии», с контрпримером, где DP не нужен.

---

## Критерии приёмки

| # | Критерий |
|---|---|
| 1 | Все обязательные `assert` в ДЗ пройдены |
| 2 | В коде явно описаны состояние и переход |
| 3 | Для DP 2D корректно обработаны границы таблицы |
| 4 | Win/lose решение совпадает с проверочными кейсами |
| 5 | Нота содержит критерии выбора DP и пример альтернативы |

---

## Вне scope

- графовый DP и сложные маршрутные задачи;
- оценка асимптотики в терминах строгих доказательств;
- `heap`/`heapq` и продвинутые структуры.
