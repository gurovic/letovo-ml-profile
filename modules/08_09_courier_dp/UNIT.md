### Описание сюжета

**Курьерская служба «Мгновение»** каждый день решает бытовые задачи: **как разменять сумму минимальным числом монет**, **какой маршрут по сетке дешевле**, **какой ход выгоднее в игре диспетчера**. На маленьких примерах можно перебрать всё, на реальных — уже нет. **Дополнительный** блок конца года: для тех, кому интересно копнуть глубже, не в ущерб обязательной практике.

---

## 2. Зачем существует модуль

**Проблема:** наивный перебор и рекурсия дают слишком дорогое решение; без DP сложно устойчиво решать задачи с повторяющимися подзадачами.

**Если убрать модуль:** в траектории остаётся разрыв между базовыми структурами и системным выбором алгоритма для оптимизации состояний.

## 5. Результаты обучения

После модуля учащийся может:

1. **Сравнить** наивную рекурсию и memoization на одинаковой задаче.
2. **Реализовать** DP 1D для размена и линейного максимума.
3. **Заполнить** DP 2D таблицу с корректными границами.
4. **Решить** игру win/lose через булево DP.
5. **Обосновать**, где DP оправдан в инженерной задаче, а где нет.
