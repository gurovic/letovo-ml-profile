# Данные модуля 08_09_courier_dp

Мини-датасеты для пар 55–59. Размер специально маленький, чтобы все примеры были прозрачны на уроке и в `solutions.ipynb`.

## Файлы

| Файл | Назначение |
|---|---|
| `coin_change_cases.csv` | Кейсы для DP 1D (размен): сумма, номиналы, ожидаемый минимум монет |
| `route_cost_grid_4x5.csv` | Сетка стоимости для DP 2D (маршрут курьера вправо/вниз) |

## Правила использования

- Загрузка данных делается из `generate_notebooks.py` через локальный поиск пути (рядом с ноутбуком и в `../../data/`).
- Данные учебные, не production, используются только для отработки переходов DP.
- В модуле не используется `heap`/`heapq`; только списки, таблицы и базовые структуры Python.
