# Артефакт модуля: эксперимент kNN для почтового сервиса

**Тип:** ноутбук / отчёт + таблица опытов + график  
**Срок:** пара КТП **29**  
**Файл сдачи:** `report` (markdown в ноутбуке или отдельный `.md`) + `experiments.csv` + `figures/config_accuracy.png`  
**На паре 29:** сборка и сдача в `lessons/06_practice_search_metrics/`

**Смысл для класса:** показать сервису baseline kNN на рукописных цифрах 8×8 с честным протоколом оценки.

Данные: [data/digits.csv](../data/digits.csv) — UCI digits через sklearn (`load_digits`), не полный MNIST 28×28.

---

## Задача

1. Зафиксировать источник и размер таблицы (1797×64 пикселя + метка).
2. Указать baseline (доля самой частой цифры) на финальной части.
3. Описать протокол: train / validation / test (ориентир 60/20/20), `stratify`, seed.
4. Перебрать настройки (`k`, при необходимости scaling / metric) **по validation**.
5. Один раз измерить качество на **test** (final).
6. Сохранить таблицу опытов и график; назвать ограничения (разрешение 8×8, скорость kNN, смещённый поток).

---

## Критерии приёмки

| # | Критерий |
|---|---|
| 1 | Указан источник `digits.csv` / UCI digits 8×8 |
| 2 | Есть baseline и итоговое число на final |
| 3 | Настройки выбраны по validation, не по final |
| 4 | Есть `experiments.csv` (или эквивалент) с ≥5 строками опытов |
| 5 | Есть ≥1 график в `figures/` с отсылкой в тексте |
| 6 | Раздел ограничений (данные / протокол / скорость) |
| 7 | Final смотрели **один** раз для отчётного числа |
| 8 | Нет CNN / полного MNIST / «подкрутки» под final |

## Решения учащегося (зафиксировать в отчёте)

1. Какое `k` (и scaling/metric) выбраны и почему.

3. Какие ограничения честно назвать заказчику.
