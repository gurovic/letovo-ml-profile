# Рукописные цифры 8×8 — сквозной датасет модуля

| Файл | Назначение |
|---|---|
| `digits.csv` | Таблица картинок цифр: метка + 64 пикселя |
| `make_digits_csv.py` | Пересборка CSV из sklearn |

## Источник

`sklearn.datasets.load_digits` — учебный набор **UCI Optical Recognition of
Handwritten Digits** (1797 картинок 8×8, значения пикселя 0…16). Набор входит в
поставку scikit-learn: работает офлайн, в Colab и без сети. **Не** синтетическая
генерация.

```bash
python make_digits_csv.py   # из каталога data/
```

## Почему не полный MNIST

| Причина | Следствие |
|---|---|
| MNIST — 784 признака, 70 000 строк | kNN на паре считается минутами, CSV в репозиторий не положить |
| 8×8 = 64 признака | картинку видно как таблицу чисел, расстояние считается вручную |
| Сюжет тот же | почтовый сервис читает цифры индекса |

Имя папки модуля `08_04_mnist_knn` — историческое; в материалах говорим
«рукописные цифры 8×8», не «MNIST».

## Столбцы

| Столбец | Смысл |
|---|---|
| `label` | цифра 0…9 — правильный ответ |
| `p00`…`p63` | яркость пикселя 0…16; порядок — построчно, `p00`…`p07` — верхняя строка картинки |

Картинка восстанавливается как 8 строк по 8 значений: `p00…p07`, `p08…p15`, …,
`p56…p63`.

Учебные ноутбуки читают **этот** `digits.csv` через `pd.read_csv`; `load_digits`
на паре не вызывается, чтобы ноутбук работал с файлом рядом.
