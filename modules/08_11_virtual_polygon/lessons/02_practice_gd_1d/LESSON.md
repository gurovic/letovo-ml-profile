### A. Чего хотим от пары

Ученик должен уметь написать рабочий численный спуск без готовых библиотек и объяснить, почему не любой `eta` хороший. Главный выход пары — связь «знак производной -> направление шага -> поведение loss».

Граница пары: только 1D и численный градиент, без многомерной математики и без формальных оценок сходимости.

## C. Если сбились

### Типичные ошибки

| Симптом / мысль ученика | Что сказать или показать |
|---|---|
| В формуле шага стоит `+ eta * grad` | Напомнить: двигаемся в сторону уменьшения, значит вычитаем градиент |
| `loss` растет, но ученик считает код верным | Предложить печатать первые 5 значений траектории |
| В траектории не хватает стартовой точки | Зафиксировать правило: длина `steps + 1` |
| `eta` выбран один и навсегда | Запустить короткий перебор 2-3 значений шага |

### Дифференциация (кратко)

| | |
|---|---|
| Слабее базы | Достаточно корректной функции GD на одной квадратичной loss |
| Сильнее базы | Добавить анализ второй функции и сравнить старты |

## D. Проектирование

### Зачем урок

Это практический центр модуля: именно здесь появляется алгоритм, который позже связывается с обучением модели и минимумом loss.

### Центральная идея

| Поле | Значение |
|---|---|
| Центральная идея | Численная производная позволяет итеративно двигаться к минимуму loss |
| Что поддерживает, но не отвлекает | Только 1D, только численные шаги, без аналитических производных |
| Данные урока | Инлайн-функции `loss` и `h` |

### Результаты обучения

См. минимум сдачи зоны A; наблюдаемость через ячейки с траекториями.

### Профессиональный контекст

В прикладном ML настройка шага обучения и проверка кривой loss — ежедневная инженерная практика при обучении моделей.
