# Артефакт модуля: виртуальный полигон минимума loss

**Тип:** итоговый мини-отчет + ноутбук с численным градиентным спуском  
**Срок:** пара КТП **68**  
**Файл сдачи:** `REPORT` и `READY=True` в `lessons/04_practice_min_loss_year_reflect/homework.ipynb`

---

## Задача

1. Реализовать численную производную для функции потерь `mse_for_w`.
2. Запустить градиентный спуск по параметру `w` и зафиксировать траекторию loss.
3. Сравнить минимум для разных стартов и разных `eta`.
4. Объяснить, почему выбранный шаг устойчив для учебной задачи.
5. Сформулировать рефлексию года и мост к 9 классу.

---

## Критерии приемки

| # | Критерий |
|---|---|
| 1 | Реализованы `num_derivative` и `gd_param` |
| 2 | Loss в корректной траектории убывает относительно старта |
| 3 | Есть сравнение минимумов для двух стартов |
| 4 | Есть сравнение поведения при двух значениях `eta` |
| 5 | Итоговый `REPORT` опирается на вычисленные значения |
| 6 | `READY=True` установлен только при выполнении критериев |
