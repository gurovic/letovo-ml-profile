# Артефакт модуля: виртуальный полигон минимума loss

**Тип:** итоговый мини-отчет + ноутбук с численным градиентным спуском  
**Срок:** пара КТП **68**  
**Файл сдачи:** `REPORT` и `READY=True` в `lessons/04_practice_min_loss_year_reflect/homework.ipynb`

---

## Задача

1. Реализовать численную производную для функции потерь `mse_for_w`.
2. Запустить градиентный спуск по параметру `w` и зафиксировать траекторию loss.
3. Сравнить минимум для разных стартов и разных `eta`.
4. Объяснить, почему выбранный шаг устойчив для учебной задачи.
5. Сформулировать рефлексию года и мост к 9 классу.

---

## Критерии приемки

| # | Критерий |
|---|---|
| 1 | Реализованы `num_derivative` и `gd_param` |
| 2 | Loss в корректной траектории убывает относительно старта |
| 3 | Есть сравнение минимумов для двух стартов |
| 4 | Есть сравнение поведения при двух значениях `eta` |
| 5 | Итоговый `REPORT` опирается на вычисленные значения |
| 6 | `READY=True` установлен только при выполнении критериев |

---

## Вне scope

- частные производные и градиент в многомерном пространстве;
- backpropagation и нейросети;
- строгие доказательства сходимости GD.

## Teacher runbook: приёмка артефакта

Минимальный маршрут от начала пары 68 до подтверждения сдачи:

1. **Открыть** `lessons/04_practice_min_loss_year_reflect/homework.ipynb` у учащегося.
2. **Запустить** ноутбук сверху вниз (Kernel → Restart & Run All); ждать завершения без ошибок.
3. **Проверить `READY`**: последняя ячейка должна печатать `READY=True`; при `False` — вернуть на доработку.
4. **Проверить `REPORT`**: текст должен содержать числовые значения (`w_final`, `mse_final`, значение `eta`); общие слова без чисел — не принимать.
5. **Критерии §2** — пройтись по таблице; отсутствующий критерий = возврат.
6. **Зафиксировать** в журнале класса: `homework.ipynb` принят; дата.

При расхождении с точным `w`: допустимо `abs(gap) < 0.02` при ≥ 40 шагах с устойчивым `eta`.
