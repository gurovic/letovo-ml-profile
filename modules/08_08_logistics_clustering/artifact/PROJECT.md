# Артефакт модуля: отчёт хаба по опозданиям и аномалиям

**Тип:** ноутбук + короткий аналитический отчёт  
**Срок:** пара КТП **54**  
**Файл сдачи:** `lessons/06_practice_clusters_anomalies/homework.ipynb`

---

## Задача

1. На потоке заказов показать корректное использование `stack`/`queue`/`deque`.
2. Через `set`/`dict` посчитать уникальность и частоты `is_late` по сегментам.
3. Подготовить признаки `delivery_days`, `freight_value`, `delay_days`.
4. Построить `KMeans` и `DBSCAN` на одном и том же срезе.
5. Выделить и объяснить аномальные заказы (шум DBSCAN и/или дальние до центроидов).
6. Сформулировать операционные рекомендации для логистического хаба.

---

## Критерии приёмки

| # | Критерий |
|---|---|
| 1 | Для потока заказов реализованы операции LIFO/FIFO и буфер `deque` |
| 2 | Есть частоты late по сегменту через `dict`, без потери total |
| 3 | Для кластеризации используются минимум 3 признака доставки |
| 4 | Получены метки и для `KMeans`, и для `DBSCAN` |
| 5 | Есть список аномалий и текстовое обоснование |
| 6 | Итоговый отчёт содержит ограничения метода |
