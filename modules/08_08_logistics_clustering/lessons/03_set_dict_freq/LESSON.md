## D. Проектирование

### Центральная идея

| Поле | Значение |
|---|---|
| Центральная идея | Hash map считает частоты сегментов; доля late — отдельный вопрос от «сколько заказов» |
| Данные | `orders_slim.csv`; метка `is_late` только для describe |

### Результаты обучения

1. Собрать `set` уникальных id и membership-проверку.
2. Построить dict-счётчики и долю late по штату.
3. Объяснить, почему топ по count ≠ топ по late_rate.

### Решения учащегося

| # | Выбор | Влияние |
|---|---|---|
| 1 | Один dict пар `(count, late)` vs два dict | Удобство и риск рассинхрона |
| 2 | Порог минимального n сегмента | Стабильность доли (подготовка к паре 52) |
