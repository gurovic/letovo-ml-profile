## D. Проектирование

### Центральная идея

| Поле | Значение |
|---|---|
| Центральная идея | Аномалия для хаба — редкая/далёкая точка с проверяемым обоснованием, а не любая late-метка |
| Данные | `orders_slim.csv` |
| Вклад в артефакт | Отчёт сегментов + список аномалий — ядро [artifact/PROJECT.md](../../artifact/PROJECT.md) |

### Результаты обучения

1. Собрать единую таблицу с метками KMeans и DBSCAN.
2. Построить профили сегментов для ops.
3. Сформировать ранжированный список аномалий с текстовым обоснованием.
4. Написать краткую записку хабу.
