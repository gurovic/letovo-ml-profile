### A. Чего хотим от пары

Главное — собрать воспроизводимый артефакт из уже отработанных частей: CLI-скрипта, зафиксированных зависимостей и README с фактической командой и метриками. Учащийся формулирует документацию как контракт передачи, а не как рассказ о проделанной работе.

Запрет `duration` должен пережить передачу проекта: README объясняет причину, CLI проверяет список признаков, а опубликованные метрики получены только без утечки.

## C. Если сбились

### Типичные ошибки

| Симптом / мысль ученика | Что сказать или показать |
|---|---|
| Создаёт `.venv` внутри сдаваемого архива | Среда пересоздаётся; передаются команды и requirements, не бинарная папка |
| Пишет `sklearn==...` | Импорт называется sklearn, distribution для установки — `scikit-learn` |
| Копирует весь `pip freeze` | Оставить прямые зависимости проекта; лишние пакеты усложняют воспроизведение |
| README содержит «запустить скрипт» без команды | Коллега должен скопировать одну точную команду |
| Метрики переписаны приблизительно | Подтянуть фактический JSON текущего запуска |
| В README нет `duration` | Это нарушение критического контракта модуля; вернуть раздел Leakage |
| Ограничение написано как «модель несовершенна» | Назвать конкретно: учебный slim-срез, один split, порог под условный бюджет |

### Дифференциация (кратко)

| | |
|---|---|
| Слабее базы | Готовые семь заголовков README; заполнить команды и фактические числа |
| Сильнее базы | Написать функцию аудита README; провести postmortem пяти рисков воспроизводимости |

## D. Проектирование

### Зачем урок

Последняя пара не вводит новую модель. Она связывает безопасный pipeline, метрики и CLI в передаваемый инженерный артефакт. Без фиксации среды и инструкции результат остаётся личным состоянием компьютера учащегося.

### Центральная идея

| Поле | Значение |
|---|---|
| Центральная идея | Воспроизводимость — проверяемый контракт среды, команды, результата и ограничений |
| Что поддерживает, но не отвлекает | Фактические метрики предыдущего CLI и gate утечки |
| Данные урока | Локальный `bank_marketing_slim.csv`; метрики CLI без `duration` |

### Результаты обучения

1. Составить последовательность команд venv для Windows.
2. Зафиксировать минимальные зависимости с версиями.
3. Написать README с точной установкой, запуском, результатами и ограничениями.
4. Проверить структуру сдачи и запрет `duration`.
5. Передать артефакт по handoff-инструкции.

### Профессиональный контекст

README и requirements — часть интерфейса эксперимента. Версия среды, seed, путь к данным и доступность признаков определяют, повторит ли коллега тот же объект исследования.

### Решения учащегося

| # | Какой выбор делает учащийся | На что влияет |
|---|---|---|
| 1 | Какие зависимости считать прямыми | Минимальность и стабильность среды |
| 2 | Какие разделы обязательны в README | Возможность воспроизвести без устных пояснений |
| 3 | Какие ограничения указать | Честность границ вывода |
