## C. Если сбились

| Симптом | Действие учителя |
|---|---|
| Неясно, что писать в README | Дать жёсткий каркас: цель -> данные -> запуск -> метрики -> ограничения |
| Пропущен запрет `duration` | Вернуть к отдельному разделу leakage rule |
| Слишком общий текст без команд | Требовать явные команды и пути запуска |

---

## D. Проектирование

- Центральная идея: инженерная ценность модели определяется воспроизводимостью, а не только числом метрик.
- Data/ML-контекст: итог модуля — воспроизводимый мини-проект по отклику на депозит.
- Материалы: `lesson.ipynb`, `homework.ipynb`, `solutions.ipynb`.
- Домашнее задание: финализировать структуру сдачи и перечислить риски воспроизводимости.
