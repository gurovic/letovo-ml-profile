# Артефакт модуля: воспроизводимый эксперимент по отклику банка

**Тип:** CLI-скрипт + `requirements.txt` + README эксперимента  
**Срок:** пара КТП **64**  
**Файл сдачи:** архив/папка `submission` по структуре ниже

---

## Задача

1. Обучить `LogisticRegression` на `bank_marketing_slim.csv`.
2. Зафиксировать запрет leakage: `duration` исключён из признаков.
3. Получить метрики `accuracy`, `precision`, `recall`, `f1` на test.
4. Запускать эксперимент одной CLI-командой.
5. Передать коллеге `requirements.txt` и README для воспроизведения.

---

## Обязательная структура сдачи

```text
submission/
  train_cli.py
  requirements.txt
  README.md
  metrics.json   # опционально: сохраненный вывод CLI
```

---

## Критерии приёмки

| # | Критерий |
|---|---|
| 1 | `train_cli.py` запускается без ошибок на slim CSV |
| 2 | В коде есть явная защита `assert "duration" not in feature_columns` |
| 3 | README содержит команду запуска и описание параметра `--threshold` |
| 4 | README содержит фактические метрики test и краткую интерпретацию |
| 5 | В `requirements.txt` зафиксированы `numpy`, `pandas`, `scikit-learn` |
| 6 | В README явно указаны ограничения учебного slim-среза |
