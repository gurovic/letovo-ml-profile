## C. Если сбились

| Симптом | Действие учителя |
|---|---|
| Валидатор «молчит» на плохих данных | Проверить условия и явный `raise ValueError(...)` |
| Ошибка неинформативна | Добавить row index/название поля в текст |
| Лог дублирует шум | Оставить только крупные шаги, полезные для диагностики |

## D. Проектирование

- Зачем урок: ввести инженерный контракт данных до сборки итоговой функции.
- Центральная идея: корректность pipeline = и трансформации, и явные проверки входа.
- Домашнее задание: обязательно, фокус на мини-валидаторе оплат.
