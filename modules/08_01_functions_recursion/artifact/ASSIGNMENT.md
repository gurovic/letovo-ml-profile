## Обозначения

Чтобы читать контракты функций без путаницы:

- **список** — `list`, например `["hello", "world"]`;
- **словарь** — `dict`, пары «ключ → значение», например `{"a": 2, "b": 1}`;
- **кортеж** — `tuple`, например `("two", 2)` (слово и частота);
- стрелка **→** значит «функция возвращает».

Фигурные скобки `{…}` в примерах — всегда **словарь**, не множество.

## Обязательные функции

Ниже — полный список. Реализуйте их в `text_stats.py` в порядке шагов выше (порядок строк в таблице не обязан совпадать с порядком кода).

| Функция | Вход | Выход | Смысл |
|---|---|---|---|
| `tokenize(text)` | строка | **список** слов в нижнем регистре | разрезать текст на слова |
| `word_frequencies(tokens)` | **список** слов | **словарь** «слово → сколько раз» | частоты |
| `filter_tokens(tokens, min_len=3)` | **список** слов; `min_len` — минимальная длина | **список** слов длины ≥ `min_len` | убрать короткие |
| `top_n(freq, n=5)` | **словарь** частот; `n` — сколько взять | **список кортежей** `(слово, частота)` по убыванию частоты | самые частые |
| `count_char_recursive(s, ch)` | две строки: текст `s` и символ `ch` | целое число | сколько раз `ch` встречается в `s`; считать **рекурсией**, без цикла по символам |
| `analyze_text(text)` | строка | **словарь** с ключами ниже | краткая сводка по одному тексту |
| `apply_pipeline(data, steps)` | значение `data` и **список функций** `steps` | результат последней функции | цепочка шагов |
| `aggregate_frequencies(texts)` | **список** строк | **словарь** «слово → суммарная частота» | частоты по целому классу отзывов |
| `compare_class_frequencies(texts_a, texts_b, ratio=2.0)` | два **списка** строк + порог `ratio` | **словарь** «слово → `"positive"` или `"negative"`» | маркерные слова |
| `naive_classify(text, texts_a, texts_b)` | строка + два **списка** отзывов | `"positive"`, `"negative"` или `"unknown"` | угадать класс |

Вспомогательная `count_words(tokens)` — по желанию: на вход список, на выход целое. Удобно вызывать из `analyze_text`.

### `analyze_text` — какой словарь вернуть

| Ключ | Тип | Что положить |
|---|---|---|
| `"word_count"` | целое | сколько слов после `tokenize` |
| `"unique_words"` | целое | сколько **разных** слов |
| `"top3"` | **список** из до трёх **кортежей** `(слово, частота)` | как `top_n(..., 3)` |

Пример для `"one two two three"`:

```python
{
    "word_count": 4,
    "unique_words": 3,
    "top3": [("two", 2), ("one", 1), ("three", 1)],
}
```

В тесте обязательно: `top3[0] == ("two", 2)`.

### `apply_pipeline` — как устроена цепочка

`steps` — список **готовых функций**. Каждая вызывается **с одним аргументом** — текущим значением:

1. `result = data`
2. для каждой функции `f` из `steps`: `result = f(result)`
3. вернуть `result`

Если функции нужен второй параметр (как `min_len` у `filter_tokens`), зафиксируйте его в `lambda`:

```python
pipeline = [
    tokenize,
    lambda tokens: filter_tokens(tokens, 3),
    word_frequencies,
]
apply_pipeline("отличный фильм", pipeline)
```

### `compare_class_frequencies` — маркеры классов

Сначала через `aggregate_frequencies` посчитайте частоты по позитивным (`texts_a`) и негативным (`texts_b`) отзывам.

Слово попадает в результат, если его частота в одном классе **не меньше** чем в `ratio` раз больше, чем в другом (по умолчанию `ratio = 2.0`). Значение в словаре — строка `"positive"` или `"negative"`.

Пример фрагмента: `{"отличный": "positive", "скучный": "negative"}`.

Отдельного теста на `aggregate_frequencies` нет: она проверяется через `compare_class_frequencies`.

### `count_char_recursive`

Пример: `count_char_recursive("banana", "a")` → `3`.

Идея рекурсии: пустая строка → `0`; иначе проверить первый символ и вызвать себя для хвоста строки.

### `naive_classify`

По маркерам из `compare_class_frequencies` посчитайте «голос» за positive и negative в новом тексте. Верните класс с большим счётом. Если счёт равный или маркеров нет — верните `"unknown"`.
