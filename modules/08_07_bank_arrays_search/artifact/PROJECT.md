# Артефакт модуля: алгоритмический отчёт по логам банка

**Тип:** аналитический ноутбук + короткий технический отчёт  
**Срок:** пара КТП **48**  
**Файл сдачи:** `REPORT` и `READY=True` в `lessons/07_complexity_integration/homework.ipynb`

---

## Задача

1. Реализовать линейный и бинарный поиск по `txn_id`.
2. Реализовать минимум одну ручную сортировку O(n²) и одну O(n log n).
3. Использовать `sorted(key=...)` на логах транзакций.
4. Решить задачу методом двух указателей на отсортированных суммах.
5. Сравнить время O(n²) и O(n log n) на 3-4 размерах входа.

---

## Критерии приёмки

| # | Критерий |
|---|---|
| 1 | `linear_search` и `binary_search` корректно работают на контрольных id |
| 2 | Ручные сортировки проходят проверки на корректность |
| 3 | Есть минимум одна задача на `sorted(key=...)` и одна на два указателя |
| 4 | Есть таблица бенчмарка с минимум тремя значениями `n` |
| 5 | В `REPORT` есть интерпретация O(n²) vs O(n log n) на данных лога |
| 6 | Вывод связан с инженерным выбором алгоритма для роста объёма данных |
