# Lesson Design: практика сортировок

## A. Сценарий пары

| Поле | Значение |
|---|---|
| Модуль | Массивы: поиск и сортировка (`08_07`) |
| Название урока | Практика: реализовать и сравнить сортировки |

| Canvas | не опубликовано |

## B. Ход пары

---

## C. Если сбились

| Симптом | Действие учителя |
|---|---|
| Время скачет между запусками | Повторить, что важен тренд, а не точные миллисекунды |
| Сравнение некорректно (разные данные) | Зафиксировать одинаковые входы для обеих функций |
| Смешивают корректность и скорость | Сначала пройти assert, потом мерить время |

---

## D. Проектирование

- Зачем урок: перевести теорию сложности в наблюдаемый эксперимент.
- Центральная идея: алгоритм выбирают по росту времени при увеличении n.
- Домашнее задание: закрепить сравнение с встроенной сортировкой.

## E. Карточка урока (§13)

| Поле | Значение |
|---|---|
| Часы | 2 |
| Стратегии обучения / виды деятельности | Практический бенчмарк сортировок на логах |
| Формирующее оценивание | Assert + проверка таблицы времени |
| Дифференциация | База - 3 размера; усиление - анализ встроенной сортировки |
| По содержанию | O(n²) vs O(n log n) через измерения |
| По процессу | Индивидуальная работа, затем общее сравнение результатов |
| По продукту | Таблица бенчмарка и вывод в ноутбуке |
| Canvas | не опубликовано |
