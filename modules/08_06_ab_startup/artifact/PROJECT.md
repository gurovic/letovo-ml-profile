# Артефакт модуля: отчёт по A/B-тесту стартапа

**Тип:** аналитический отчёт + ноутбук с расчётами  
**Срок:** пара КТП **41**  
**Файл сдачи:** `REPORT` и `READY=True` в `lessons/06_practice_report/homework.ipynb`

---

## Задача

1. Посчитать конверсию для `A` и `B`.
2. Проверить различие через перестановочный `p-value`.
3. Построить 95% CI для uplift (`conv_B - conv_A`).
4. Добавить регрессионную интерпретацию факторов (`LinearRegression`).
5. Зафиксировать ограничения и риски интерпретации.

---

## Критерии приёмки

| # | Критерий |
|---|---|
| 1 | Есть метрика конверсии `A` и `B` и uplift |
| 2 | `p-value` рассчитан симуляцией/перестановками |
| 3 | Есть 95% CI для uplift |
| 4 | Есть таблица коэффициентов множественной регрессии |
| 5 | В отчёте отдельно отражены риски `peeking` и «корреляция ≠ причинность» |
| 6 | Итоговый вывод согласован с числами и ограничениями |

---

## Вне scope

- байесовский A/B;
- логистическая регрессия и калибровка вероятностей;
- причинный вывод (DAG, matching).
