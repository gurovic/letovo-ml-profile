# Данные модуля 08_06: A/B стартапа

Источник данных в модуле — синтетический CSV `startup_ab.csv` (офлайн, без Kaggle).

## Как собрать

```bash
python modules/08_06_ab_startup/data/make_startup_ab_csv.py
```

Скрипт использует фиксированный `SEED = 806`, поэтому у всех одинаковые значения и одинаковые ответы в `solutions`.

## Что в таблице

| Поле | Смысл |
|---|---|
| `user_id` | идентификатор визита |
| `day` | день эксперимента (1..30) |
| `variant` | вариант лендинга: `A` или `B` |
| `device` | `desktop` / `mobile` |
| `traffic_source` | канал: `ads`, `search`, `social`, `direct` |
| `age` | возраст пользователя |
| `session_minutes` | длительность сессии |
| `pages_viewed` | число просмотренных страниц |
| `prior_visits_30d` | визиты пользователя за 30 дней до текущего |
| `discount_pct` | размер скидки в эксперименте |
| `is_weekend` | 1, если визит в выходной |
| `converted` | целевое действие (0/1) |
| `order_value` | выручка по визиту (0, если не конвертировался) |

## Какие задачи покрывает датасет

1. Конверсия `A` vs `B`.
2. Перестановочный/симуляционный `p-value`.
3. Доверительные интервалы для долей и разности долей.
4. Корреляция и её ограничения (корреляция не доказывает причинность).
5. Риск peeking (подглядывания по дням эксперимента).
6. Множественная линейная регрессия (`LinearRegression`) и интерпретация коэффициентов.
