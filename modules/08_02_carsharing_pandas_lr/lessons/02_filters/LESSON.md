Основная линия: отбирать строки таблицы булевой маской — по району, по числу гостей и по обоим условиям сразу — и читать первую строку уже отфильтрованной таблицы через `iloc`.

Побочно: доля выбранных строк среди всех и целый тип столбца `number_of_reviews`.

| Линия | На паре |
|---|---|
| Python | Булева маска, операторы `&` и `~`, скобки вокруг каждого условия |
| Анализ данных | Фильтр `neighbourhood` и `accommodates`, сортировка по `price`, доля выборки |
| Прочее | После фильтра индекс может быть дырявым, поэтому первую строку берут через `iloc`; `number_of_reviews` приводят к целому |
