# Экзаменатор (sim-examiner)

## Роль

Принять «экзамен» у одного студента после прохождения программы:
сопоставить итоговые состояния тем с пятью компетенциями Foundation §3
и вынести вердикт по каждой.

## Пять компетенций (Foundation §3)

| Ключ | Компетенция |
|---|---|
| C1_programming | Программирует как инженер |
| C2_data | Работает с данными |
| C3_ml | Применяет ML |
| C4_math | Мыслит математически |
| C5_artifacts | Создаёт артефакты |

## Логика оценки

| Состояние темы | Вклад в балл |
|---|---|
| mastered | 1.0 × weight |
| practiced | 0.6 × weight |
| met | 0.2 × weight |
| forgotten / unseen | 0.0 |

Порог «сформировано»: score ≥ 0.65 по компетенции.
Портрет выпускника сформирован: все C1–C5 passed.

Веса тем — в `sim/competency_map.yaml` → `weights`.

## Workflow

```
1. Получить SimResult (из sim-student или из лога run.py --verbose).

2. Запустить экзамен:
   python sim/run.py --students 1 --seed <N>
   (вывод уже содержит ExamReport)

3. Прочитать вывод:
   - Какие компетенции passed / failed?
   - Какие топ-пробелы (gap_summary)?

4. Если нужен ручной разбор — прочитать sim/examiner.py::examine()
   и вызвать напрямую из REPL или скрипта.
```

## Формат ExamReport

```markdown
## Результат экзамена — студент #N
Capacity: 0.82  |  Итоговый балл: 0.73  |  Портрет выпускника: ✓ сформирован

| Компетенция | Балл | Статус |
|---|---|---|
| Программирует как инженер | 0.78 | ✓ |
| Работает с данными | 0.70 | ✓ |
| Применяет ML | 0.65 | ✓ |
| Мыслит математически | 0.58 | ✗ |
| Создаёт артефакты | 0.80 | ✓ |

**Топ пробелов:**
- производная как скорость изменения
- H₀/H₁ и p-value
```

## Когда применять

- Для ручного анализа конкретного студента (edge case: очень слабый / сильный).
- При разработке новых порогов или весов (`competency_map.yaml`).
- После изменения программы — сравнить ExamReport до и после.

## Файлы
